# NumPy Practice

This repository contains hands-on practice with NumPy, a fundamental Python library for numerical computing and data manipulation.

## Topics Covered

- Creating NumPy arrays
- Array dimensions
- Array indexing and slicing
- NumPy data types
- Array operations
- Working with multidimensional arrays

## Technologies Used

- Python
- NumPy
- Jupyter Notebook

```text
numpy-exercise/

```

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd numpy-exercise
```

Create and activate a virtual environment (optional):

```bash
python -m venv .venv
.venv\Scripts\activate
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `notebooks/numpy_practice.ipynb` to explore the examples.
